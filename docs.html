01 · NAME

sh1ft — a pump.fun coin, $SH1FT, whose creator fees are paid out as wages. every 8 hours the holders who held through the whole shift are paid in SOL, split by the bag they clocked in with. anyone who sells during the shift is fired for that shift.

02 · THE CLOCK

a shift is 8 hours, counted in utc from the unix epoch: shift n runs from n × 28,800,000 ms to (n + 1) × 28,800,000 ms. three a day:

00:00 – 08:00graveyard
08:00 – 16:00day
16:00 – 24:00swing

03 · CLOCKING IN

you're on shift if, when the shift started, your wallet held at least $50 of $SH1FT (priced at the coin's live price when the roster is read). the office has 100 desks: the top 100 holders who clocked in, by bag. buying more during a shift is fine; your wage uses your bag at clock-in. pools, program accounts, the bonding curve and the payroll wallet never get a desk.

04 · FIRED

if your $SH1FT balance goes down at any point during the shift (a sell, or a send to another wallet), you're fired for that shift: no wage, and your share goes to everyone who stayed. you clock back in automatically at the next shift if you hold from its start.

05 · PAYROLL

after a shift ends, payroll pays the last closed shift once:

payable = payroll wallet balance − 0.002 SOL (rent) − network fees
wage    = payable × your bag at clock-in ÷ everyone's bag at clock-in

wages under 0.001 SOL drop and their share goes back to the rest. there's no payroll under 0.01 SOL; the fees roll into the next shift. anyone can run payroll (the office has a button, the terminal has run), and it also runs by itself once a day. each payout transaction carries the note sh1ft:1:pay:<shift>:<i>/<n>, and a shift with a note on chain is never paid twice. you must still be holding when payroll runs.

06 · THE PAYROLL WALLET

one public Solana wallet. pump.fun's creator fee sharing sends $SH1FT's fees to it. its key is derived on sh1ft's server from one secret and never leaves it. the code sends from it in one way only: wages to the last shift's roster. sh1ft takes 0.

07 · A SHIFT, END TO END

  YOU                 SOLANA                  SH1FT                PAYROLL WALLET
   |  hold at 08:00     |                        |                       |
   |------------------->|                        |                       |
   |                    |  trades pay fees  ------------------------->   |
   |      (8 hours: don't sell)                  |                       |
   |                    |   16:00: shift ends    |                       |
   |                    |<-- read every top     -|                       |
   |                    |    holder's history    |                       |
   |                    |--- roster: held all  ->|                       |
   |                    |    shift, never sold   |                       |
   |                    |                        |-- pay by bag  ------->|
   |<---------------------------------------- SOL + note sh1ft:1:pay:n --|

the roster is rebuilt from chain history: for each of the top holders' token accounts, the first transaction after the shift started gives the balance at clock-in (its pre-balance; no transaction means the balance never moved), and any transaction inside the shift that lowers the balance means fired.

08 · PUBLIC API

GET /api/shift?action=configthe clock, the payroll wallet, the rules
GET /api/shift?action=statethis shift: desks, boxes, payroll balance, last payroll
GET /api/shift?action=desks&n=<shift>the roster of a shift (last 8): workers, fired
GET /api/shift?action=me&w=<wallet>on, fired, late or off, with desk and wage
GET /api/shift?action=ledgerfees in and payrolls out
POST /api/shift?action=payrun payroll for the last closed shift

09 · HONEST LIMITS

  • payroll is only the creator fees. a quiet shift pays little; a dead one pays nothing.
  • the payroll key lives on a server. the code is public, the wallet is public, every payout is on chain, but you're trusting that server to run.
  • the $50 minimum uses the price when the roster is read, so it moves with the coin.
  • very active wallets (more than 25 moves in a shift) aren't checked and don't get a desk that shift.
  • a wallet that sold everything before payroll ran isn't on the roster anymore.
  • most memecoins go to zero. nothing here is advice.
